## What's supported

### Supported actions

This connector supports:

- [Read Actions](/read-actions), including full historic backfill. Please note that incremental read is supported only for `tasks` and `time_entries` currently. For all other objects, a full read of the ClickUp instance will be done per scheduled read.
- [Proxy Actions](/proxy-actions), using the base URL `https://api.clickup.com/api`.

### Notes

- Incremental read uses the date a task was last updated for `tasks`, and the start date of a time entry for `time_entries`.

## Before you get started

To integrate ClickUp with Ampersand, you will need a [ClickUp account](https://app.clickup.com/signup).

Once your account is created, you'll need to create a ClickUp app and obtain the following credentials from it:

- Client ID
- Client Secret

You will then use these credentials to connect your application to Ampersand.

When your customer installs the integration, they enter the ID of the ClickUp Workspace to connect. ClickUp's API calls a Workspace a "team", so this ID is also called the Team ID. Your customer can find it in either of these places:

- In the ClickUp web app, it's the number right after `app.clickup.com/` in the URL. For example, if the URL is `https://app.clickup.com/9012345678/home`, the Workspace ID is `9012345678`.
- The [Get Authorized Workspaces](https://developer.clickup.com/reference/getauthorizedteams) endpoint lists the Workspaces the user can access; the `id` of each entry in `teams` is a Workspace ID.

### Create a ClickUp account

Here's how you can sign up for a ClickUp account:

- Go to the [ClickUp Sign Up page](https://app.clickup.com/signup) and create an account.
- Sign up using your preferred method.

### Creating a ClickUp app

1. Log in to your [ClickUp](https://app.clickup.com/settings/apps) account.
2. Click **+Create an App**.
3. Enter your **App Name**.
4. Set the redirect URL to: `https://api.withampersand.com/callbacks/v1/oauth`
5. Click **Create App**.

   ![Alt text](/images/provider-guides/62de7c7-clickup1.gif)

6. On the next screen, copy the generated **Client ID** and **Client Secret**.

### Add your ClickUp app info to Ampersand

1. In the [Ampersand Dashboard](https://dashboard.withampersand.com), open the project for your ClickUp integration and go to **Provider apps**.

   ![Alt text](/images/provider-guides/dd47b7a-Ampersand.png)

2. Click **+ New App**.

3. Select **ClickUp** from the **Provider** list.

4. Enter the **Client ID** and **Client Secret** obtained from your ClickUp app.

   ![Alt text](/images/provider-guides/d1a4278-clickup2.gif)

5. Click **Save changes**.

## Using the connector

To start integrating with ClickUp:

- Create a manifest file like the [example above](#example-integration).
- Deploy it using the [amp CLI](/cli/overview).
- If you are using Read Actions, create a [destination](/destinations).
- Embed the [InstallIntegration](/embeddable-ui-components#install-integration) UI component. The UI component will prompt the customer for OAuth authorization and their Workspace (Team) ID.
- Start using the connector!
   - If your integration has [Read Actions](/read-actions), you'll start getting webhook messages.
   - If your integration has [Proxy Actions](/proxy-actions), you can start making Proxy API calls.
