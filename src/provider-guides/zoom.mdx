## What's supported

### Supported actions

This connector supports:

- [Read Actions](/read-actions), including full historic backfill. Incremental reading is supported for the objects listed below. For all other objects, a full read of the Zoom instance will be done per scheduled read.
- [Write Actions](/write-actions).
- [Proxy Actions](/proxy-actions), using the base URL `https://api.zoom.us`.

### Notes

- The following objects don't support full historic backfill: `meeting_activities_report`, `meetings_report`, `operation_logs_report`, `recordings`, `recordings_report`, `telephone_report`, `upcoming_events_report` and `users_report`. By default, the last 29 days are read. To read further back, set a longer `defaultPeriod` in the object's [backfill configuration](/read-actions#limited-time-backfill).

## Before you get started

To integrate Zoom with Ampersand, you will need a [Zoom account](https://zoom.us/signup).

Once your account is created, you'll need to create a Zoom app and obtain the following credentials from it:

- Client ID
- Client Secret

You will then use these credentials to connect your application to Ampersand.

### Creating a Zoom app

1. Log in to the [Zoom developer portal](https://marketplace.zoom.us/).
2. Click **+** next to **Developer** and select **Build app**.
3. Select **General app**, then click **Create**.

   <video autoPlay muted loop playsInline className="w-full rounded-xl" src="/images/provider-guides/zoom-app-create.mp4"></video>

4. In the **OAuth information** section, set the redirect URL to: `https://api.withampersand.com/callbacks/v1/oauth`
5. Go to **Scopes**.
6. Click **Add scopes** and select the scopes your app uses.

   <video autoPlay muted loop playsInline className="w-full rounded-xl" src="/images/provider-guides/zoom-app-scopes.mp4"></video>

7. Go to **Local test** and click **Add app now** to finish setting up your app.
8. Copy the **Client ID** and **Client Secret** from the **Basic information** section of the app.

   <video autoPlay muted loop playsInline className="w-full rounded-xl" src="/images/provider-guides/zoom-app-credentials.mp4"></video>

### Add your Zoom app info to Ampersand

1. In the [Ampersand Dashboard](https://dashboard.withampersand.com), open the project for your Zoom integration and go to **Provider apps**.

2. Click **+ New App**.

3. Select **Zoom** from the **Provider** list.

4. Enter the **Client ID** and **Client Secret** obtained from your Zoom app.

5. Click **Save changes**.

<video autoPlay muted loop playsInline className="w-full rounded-xl" src="/images/provider-guides/zoom-ampersand.mp4"></video>

## Using the connector

To start integrating with Zoom:

- Create a manifest file like the [example above](#example-integration).
- Deploy it using the [amp CLI](/cli/overview).
- If you are using Read Actions, create a [destination](/destinations).
- Embed the [InstallIntegration](/embeddable-ui-components#install-integration) UI component. The UI component will prompt the customer for OAuth authorization.
- Start using the connector!
   - If your integration has [Read Actions](/read-actions), you'll start getting webhook messages.
   - If your integration has [Write Actions](/write-actions), you can start making API calls to our Write API.
   - If your integration has [Proxy Actions](/proxy-actions), you can start making Proxy API calls.
