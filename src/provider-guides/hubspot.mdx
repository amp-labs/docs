## What's Supported

### Supported Actions

The Hubspot connector supports:

- [Read Actions](/read-actions), including full historic backfill, incremental reads, and filters.
- [Subscribe Actions](/subscribe-actions). Setup is in [Set up Subscribe Actions](#set-up-subscribe-actions). Custom field changes are in [Subscribe to HubSpot custom fields](/additional-setup/hubspot-subscribe-custom-fields).
- [Write Actions](/write-actions), including Bulk Write and Delete.
- [Proxy Actions](/proxy-actions), using the base URL `https://api.hubapi.com`.

### Supported Objects

#### CRM Objects

The connector supports reading from and writing to the following *CRM objects*,
including [standard fields](https://docs.google.com/spreadsheets/d/1FGc9zT_J9dyGghDxvqeioAva-5Gj7-2DQzKNMrbrPvw/view?usp=sharing) and custom fields:

- [calls](https://developers.hubspot.com/docs/api-reference/legacy/crm/activities/calls/guide)
- [companies](https://developers.hubspot.com/docs/api-reference/legacy/crm/objects/companies/guide)
- [contacts](https://developers.hubspot.com/docs/api-reference/legacy/crm/objects/contacts/guide)
- [deals](https://developers.hubspot.com/docs/api-reference/legacy/crm/objects/deals/guide)
- [emails](https://developers.hubspot.com/docs/api-reference/legacy/crm/activities/emails/guide)
- [meetings](https://developers.hubspot.com/docs/api-reference/legacy/crm/activities/meetings/guide)
- [notes](https://developers.hubspot.com/docs/api-reference/legacy/crm/activities/notes/guide)
- All other [standard CRM objects](https://developers.hubspot.com/docs/guides/crm/understanding-the-crm#object-type-ids)
- Custom CRM objects

The connector only supports reading from:
- [lists](https://developers.hubspot.com/docs/api-reference/latest/crm/lists/guide) (note: incremental reads not supported for Lists)
- Users and owners ([see below](#reading-users-and-owners))

#### Marketing Objects
The connector supports reading from:
- [marketing-campaigns](https://developers.hubspot.com/docs/api-reference/latest/marketing/campaigns/guide)
- [marketing-forms](https://developers.hubspot.com/docs/api-reference/2026-09-beta/marketing/forms/guide)
- [marketing-events](https://developers.hubspot.com/docs/api-reference/latest/marketing/marketing-events/guide)
- [marketing-emails](https://developers.hubspot.com/docs/api-reference/latest/marketing/marketing-emails/guide)

#### Conversation Objects
The connector supports reading from:
- [channel-accounts](https://developers.hubspot.com/docs/api-reference/2026-09-beta/conversations/conversations/channel-accounts/get-channel-accounts)
- [channels](https://developers.hubspot.com/docs/api-reference/2026-09-beta/conversations/conversations/channels/get-channels)
- [custom-channels](https://developers.hubspot.com/docs/api-reference/latest/conversations/custom-channels/channels/get-custom-channels)
- [inboxes](https://developers.hubspot.com/docs/api-reference/2026-09-beta/conversations/conversations/inbox/get-inboxes)
- [threads](https://developers.hubspot.com/docs/api-reference/2026-09-beta/conversations/conversations/threads/get-threads)

#### Communication Objects
The connector supports reading from:
- [communication-preferences](https://developers.hubspot.com/docs/api-reference/latest/communication-preferences/guide)

#### Scheduler Objects
The connector supports reading from:
- [meeting-links](https://developers.hubspot.com/docs/api-reference/latest/scheduler/meetings/get-meeting-links)

#### Event Occurrences

Read an event type as its own object: `AMPERSAND-event-occurrences-<EVENT_TYPE>`.

<Note>
  **occurrences** is spelled with two c's and two r's.
</Note>

* `AMPERSAND-event-occurrences-e_call_ended`
* `AMPERSAND-event-occurrences-e_form_submission`
* `AMPERSAND-event-occurrences-e_mta_bounced_email_v2`
* `AMPERSAND-event-occurrences-e_visited_page`
* `AMPERSAND-event-occurrences-pe148543157_this_is_my_event`

Standard event type names begin with `e_` and work for every customer. Custom event definitions use that account's `fullyQualifiedName`, which starts with `pe{HubId}_`, and work only in the account where they are defined.

To find an event type, use HubSpot's [list event types](https://developers.hubspot.com/docs/api-reference/latest/events/retrieve-events/get-event-types) endpoint and [list custom event definitions](https://developers.hubspot.com/docs/api-reference/latest/events/define-events/create-event-definition).

#### Reading users and owners

To read users from your customer's HubSpot workspace, enable the `crm.objects.users.read` scope and add `users` as an object in `amp.yaml`:

```YAML
- objectName: users
  destination: defaultWebhook
  schedule: "0 0 * * *"
  requiredFields:
    - fieldName: hs_object_id
      mapToName: userId
    - fieldName: hubspot_owner_id
      mapToName: ownerId
    - fieldName: hs_email
      mapToName: emailAddress
```

## Create a HubSpot App

Pick one way to create the app:

- [New project app](#method-1-new-project-apps), using the HubSpot CLI. Limited to 25 installs until the app is listed on the HubSpot Marketplace.
- [Legacy app, account created after September 2025](#developer-accounts-created-after-september-2025)
- [Legacy app, account created before September 2025](#developer-accounts-created-before-september-2025)

Legacy apps have no install limit. They do not receive new HubSpot features. Details are in [Method 2](#method-2-legacy-apps).

### Method 1: New Project Apps

New Project Apps are [limited to 25 installs](https://developers.hubspot.com/changelog/new-marketplace-distribution-app-install-limits) until the app is listed on the HubSpot Marketplace. Start [publishing to the HubSpot marketplace](#publish-to-hubspot-marketplace) once the integration is tested.

#### Install and log in to the HubSpot CLI

Skip to [Create the project](#create-project) if the HubSpot CLI is already authenticated.

1. Open a terminal.
2. Install the HubSpot CLI: `npm install -g @hubspot/cli`
3. Run `hs account auth` and select open HubSpot to get your key. If you already have a personal access key, select **Enter existing personal access key**.

   ![Alt text](/images/provider-guides/hubspot-cli-account-auth.png)

4. Select your account, if prompted.

<Note>
  If you have multiple accounts, select the developer account.
</Note>

5. Create a personal access key and copy it.

   ![Alt text](/images/provider-guides/hubspot-cli-create-key.gif)

6. Paste the key in the terminal and press Enter.

   ![Alt text](/images/provider-guides/hubspot-cli-paste-key.png)

#### Create the project

1. Run:

```
hs project create --name your-project-name --project-base app --distribution marketplace --auth oauth --features
```

2. Open the project folder and edit `src/app/app-hsmeta.json`. Replace the `auth` section with the snippet below. Add scopes for any objects besides contacts. To read companies, add `crm.objects.companies.read`. The full list is in [HubSpot's scopes documentation](https://developers.hubspot.com/docs/apps/developer-platform/build-apps/authentication/scopes#list-of-available-scopes).

```json
{
  "auth": {
   "type": "oauth",
   "redirectUrls": ["https://api.withampersand.com/callbacks/v1/oauth"],
   "requiredScopes": [
      "oauth",
      "crm.objects.contacts.read",
      "crm.objects.contacts.write"
   ],
   "optionalScopes": [],
   "conditionallyRequiredScopes": []   
  }
}
```

3. Deploy:

```
hs project upload
```

When prompted to create the project, select yes.

![Alt text](/images/provider-guides/hubspot-cli-deploy-project.png)

#### Accept HubSpot's Acceptable Use Policy

The first time you create a HubSpot app, accept the Acceptable Use Policy before anyone can install the integration.

1. Log in to HubSpot.
2. Select **Development** at the bottom of the left nav.

<img width="250" src="/images/provider-guides/hubspot-development-tab.png" alt="Dev tab" />

3. Select the project you just created.

<img src="/images/provider-guides/hubspot-select-project.png" alt="Select Project" />

4. Under **Project Components**, click the app.

<img src="/images/provider-guides/hubspot-select-app.png" alt="Select App" />

5. Open the **Distribution** tab, click **Begin Publishing**, and complete **Agree to HubSpot's Acceptable Use Policy**. You can stop there.

#### Copy the client ID and client secret

Open the app the same way as the previous section, then open the **Auth** tab.

![Auth](/images/provider-guides/hubspot-auth.png)

Then [add the app in Ampersand](#add-app-to-ampersand).

### Method 2: Legacy Apps

<Note>
  Legacy apps have no install limit, but they [won't receive new HubSpot features](https://developers.hubspot.com/docs/apps/developer-platform/build-apps/overview). Migrating one to a new project app brings back the 25-install limit until the app is listed on the HubSpot marketplace. See the [HubSpot changelog](https://developers.hubspot.com/changelog/new-marketplace-distribution-app-install-limits).
</Note>

Where you start depends on when the developer account was created. The auth, scopes, and client ID steps are the same after that.

#### Developer accounts created after September 2025

1. Log in to your HubSpot developer account.
2. Go to **Development**, then **Legacy apps**.

   ![Alt text](/images/provider-guides/hubspot-new-dev-1.gif)

<Note>
  If you don't see the Development menu, you need Super Admin permissions.
</Note>

3. Click **Create**, then select **Public**.

   ![Alt text](/images/provider-guides/hubspot-new-create-legacy-app.gif)

#### Developer accounts created before September 2025

1. Log in to your [HubSpot Developer Dashboard](https://app.hubspot.com/signup-hubspot/developers).
2. Click **Create an app**.

   ![Alt text](/images/provider-guides/a8c2c6f-hubspot1.gif)

#### Finish the app

1. Enter the **Public app name** and open the **Auth** tab. Add this redirect URL, then click **Create app**: `https://api.withampersand.com/callbacks/v1/oauth`

   ![Alt text](/images/provider-guides/hubspot-old-portal-2.gif)

2. Open **Scopes**, click **Add new scope**, and select the scopes you need.

   ![Alt text](/images/provider-guides/1b56fb4-hubspot5.gif)

3. Copy the **Client ID** and **Client Secret** from the **Auth** tab.

   ![Alt text](/images/provider-guides/hubspot-old-portal-3.gif)

Then [add the app in Ampersand](#add-app-to-ampersand).

## Add App to Ampersand

After creating your app using any method above:

1. Log in to your [Ampersand Dashboard](https://dashboard.withampersand.com)
2. Select your project → **Provider apps**
3. Select **HubSpot** from the Provider list
4. Enter your **Client ID**, **Client Secret**, and **Scopes** and click **Save changes**.

<Note>
   These scopes must match the exact set of scopes defined in your HubSpot app.
</Note>

   ![Alt text](/images/provider-guides/f4ada70-hubspot6.gif)

## Set up Subscribe Actions

<Note>
  Subscriptions on your HubSpot app cover standard fields. To receive changes to custom fields, see [Subscribe to HubSpot custom fields](/additional-setup/hubspot-subscribe-custom-fields).
</Note>

Define the subscribe action in `amp.yaml` and deploy it. See [Subscribe actions](/subscribe-actions). Then add webhooks on the HubSpot app:

- [New project apps](#new-project-apps) if you created the app with the HubSpot CLI.
- [Legacy apps](#legacy-apps) if you created it in the HubSpot UI.


### New project apps

If you are using a new project app (that was created with the HubSpot CLI), then follow the instructions below. If you don't have any apps yet, follow the instructions in [Method 1: New Project Apps](#method-1-new-project-apps) above to create one.

#### Create webhooks-hsmeta.json file

Go to the directory that contains your HubSpot app, and add a file called `your-project-name/src/app/webhooks/webhooks-hsmeta.json`. So your directory should end up like this:

```
/your-project-name
  /src/app
    /webhooks
      webhooks-hsmeta.json
    app-hsmeta.json
  hsproject.json
```

Replace `targetUrl` in the example `webhooks-hsmeta.json` file below with the one that is for your integration. It should follow the format:

```
"https://subscribe-webhook.withampersand.com/v1/projects/PROJECT_ID/integrations/INTEGRATION_ID"
```

- `PROJECT_ID` is in the dashboard URL when you open the project: `/projects/PROJECT_ID/...`
- `INTEGRATION_ID` is the next ID when you open the integration: `/projects/PROJECT_ID/integrations/INTEGRATION_ID`

You can also edit the file with the desired objects and events you want to subscribe to. You can refer to [HubSpot documentation](https://developers.hubspot.com/docs/apps/developer-platform/add-features/configure-webhooks#webhook-configuration) for the syntax of this file.

Example `webhooks-hsmeta.json`:
```
{
  "uid": "ampersand_subscribe_actions",
  "type": "webhooks",
  "config": {
    "settings": {
      "targetUrl": "SEE_INSTRUCTIONS_ABOVE",
      "maxConcurrentRequests": 50
    },
    "subscriptions": {
      "crmObjects": [
        {
          "subscriptionType": "object.creation",
          "objectType": "contact",
          "active": true
        },
        {
          "subscriptionType": "object.propertyChange",
          "objectType": "contact",
          "propertyName": "firstname",
          "active": true
        },
        {
          "subscriptionType": "object.propertyChange",
          "objectType": "contact",
          "propertyName": "lastname",
          "active": true
        },
        {
          "subscriptionType": "object.deletion",
          "objectType": "contact",
          "active": true
        }
      ]
    }
  }
}
```

#### Deploy changes to HubSpot

Once you are done editing `webhooks-hsmeta.json`, deploy it using the following command:

```
hs project upload
```

### Legacy apps

If you have a legacy app (that was created in the HubSpot UI), follow the instructions below.

1. Log in to your HubSpot account.
2. Go to the **Apps** section.
3. Select your connected app.
4. Click **Webhooks**.
5. Enter this target URL:

   ```
   https://subscribe-webhook.withampersand.com/v1/projects/PROJECT_ID/integrations/INTEGRATION_ID
   ```

   - `PROJECT_ID` is in the dashboard URL when you open the project: `/projects/PROJECT_ID/...`
   - `INTEGRATION_ID` is the next ID when you open the integration: `/projects/PROJECT_ID/integrations/INTEGRATION_ID`

6. Click **Create Subscription**.
7. Select the object types, event types, and properties.
8. Select the required checkboxes for all objects.
9. Click **Activate**.

## Publish to HubSpot Marketplace

When you are ready to list on the HubSpot marketplace, follow the instructions in the [HubSpot documentation](https://developers.hubspot.com/docs/apps/developer-platform/list-apps/listing-your-app/listing-your-app).

- For the **App Information** section, you should use information about your company, not about Ampersand.
- For **Install Button URL**, use the URL of your application that users go to in order to start the installation process (this is usually where you've embedded the Ampersand UI Component).
