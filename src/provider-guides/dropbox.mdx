## What's supported

### Supported actions

This connector supports:

- [Read Actions](/read-actions), including historic backfill where a record timestamp is available. Incremental reads use object-specific datetime fields (see [Notes and limitations](#notes-and-limitations)).
- [Write Actions](/write-actions) (create and update for **file requests** only).
- [Proxy Actions](/proxy-actions), using the base URL `https://api.dropboxapi.com`.
- Subscribe Actions are not currently supported.

### Notes and limitations

- **Write support:** `file_requests` supports create and update only. Other objects in the table are read-only through Write Actions.
- **Files (`read`):** Lists items in the connected account’s **root** folder (one directory level, not a full recursive tree).
- **Incremental read:** `since` / `until` use these fields per object: `files` and `shared_links` — server modified; `file_requests` — created; `shared_folders`, `mountable_shared_folders`, and `received_files` — time invited.
- **App type:** Sharing-related read objects require a **Full Dropbox** app. **App folder** apps cannot use all sharing list APIs. Grant OAuth scopes that match your manifest objects (see [Create a Dropbox app](#create-a-dropbox-app) and [Dropbox permissions](https://docs.dropboxapi.com/dropbox-api/docs/permissions/basics)).

## Before you get started

To integrate Dropbox with Ampersand, you need a [Dropbox account](https://www.dropbox.com/register) and a **Dropbox API app** in the [App Console](https://www.dropbox.com/developers/apps).

From that app you will need:

- **App key** (OAuth client ID)
- **App secret** (OAuth client secret)

You will use these credentials when you connect the integration in Ampersand. Your customers complete Dropbox’s OAuth flow when they install your app.

For background, see [Dropbox’s OAuth guide](https://docs.dropboxapi.com/dropbox-api/docs/developers/oauth-guide).

### Create a Dropbox app

1. Log in to the [Dropbox App Console](https://www.dropbox.com/developers/apps).
2. Click **Create app**.
3. Select **Scoped access**.
4. Choose **Full Dropbox** (recommended if you use sharing-related read objects) or **App folder**, depending on your product. App folder apps cannot use all sharing list APIs.
5. Enter a name for your app.

![Create a Dropbox app](/images/provider-guides/6d3f25b-dropbox-app-create.gif)

6. Accept the **Dropbox API Terms and Conditions**.
7. Click **Create app**.

In the app **Settings** tab, copy the **App key** and **App secret**. You will enter them in Ampersand as Client ID and Client Secret.

### Set permissions (scopes)

1. Open the **Permissions** tab for your app.
2. Enable the scopes your integration needs (at minimum those for the objects in your manifest).

![Dropbox app permissions](/images/provider-guides/b546e59-dropbox-scopes.gif)

### Add the Ampersand redirect URI

1. In **Settings**, under **OAuth 2 → Redirect URIs**, add:

   `https://api.withampersand.com/callbacks/v1/oauth`

![Dropbox OAuth redirect URI](/images/provider-guides/91eaa5d-dropbox-redirect-uri.gif)

During customer installation, Dropbox prompts the user to **Allow** your app.

## Add your Dropbox app to Ampersand

1. Log in to your [Ampersand Dashboard](https://dashboard.withampersand.com).

2. Select the project where you want to create a Dropbox integration.

   ![Ampersand project selection](/images/provider-guides/dd47b7a-Ampersand.png)

3. Select **Provider apps**.

4. Select _Dropbox_ from the **Provider** list.

5. Enter the **App key** in the **Client ID** field and the **App secret** in the **Client Secret** field.

![Add Dropbox credentials in Ampersand](/images/provider-guides/b4cc0e4-dropbox2.gif)

6. Click **Save changes**.

## Using the connector

To start integrating with Dropbox:

- Create a manifest file like the [example](https://github.com/amp-labs/samples/blob/main/dropbox/amp.yaml).
- Deploy it using the [amp CLI](/cli/overview).
- If you are using Read Actions, create a [destination](/destinations).
- Embed the [InstallIntegration](/embeddable-ui-components#install-integration) UI component so customers can complete Dropbox OAuth.
- Start using the connector:
  - With [Read Actions](/read-actions), synced records are delivered to your destination on the schedule you define.
  - With [Write Actions](/write-actions), create and update **file requests** (see [create](https://docs.dropboxapi.com/dropbox-api/api-reference/user-endpoints/file-requests/create) and [update](https://docs.dropboxapi.com/dropbox-api/api-reference/user-endpoints/file-requests/update)).
  - With [Proxy Actions](/proxy-actions), call the Dropbox user API at `https://api.dropboxapi.com` using the customer’s OAuth token.
