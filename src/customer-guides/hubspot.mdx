## Checklist before installing a HubSpot integration

We recommend verifying the following requirements before installing the HubSpot integration to ensure a smooth setup.

### 1. Ensure you are a HubSpot Super Admin

You must be a **Super Admin** to install an app. This is a [HubSpot requirement](https://developers.hubspot.com/docs/apps/developer-platform/build-apps/authentication/oauth/oauth-quickstart-guide).

### 2. Ensure you have a Sales Hub seat (if access to Leads is required)

If your integration requires access to Leads, you must have a Sales Hub seat in HubSpot. Without this, you may not be able to retrieve or manage lead data.

To check if you have a Sales Hub seat:

1. Log in to *HubSpot*.
2. Click on your profile picture and select **Settings**.
3. In the left sidebar, navigate to **Users & Teams**.
4. Locate your user account and check for **Sales Hub seat** assignment.
5. If you do not have a Sales Hub seat, ask your HubSpot administrator to assign one to you.

Learn more about different HubSpot seats [here](https://knowledge.hubspot.com/account-management/manage-seats).

## Set up a private app for custom field changes

If the app you're integrating with needs to know when custom fields change in HubSpot, it asks you to create a private app in your HubSpot account. You must be a HubSpot **Super Admin**.

1. Get the webhook URL from the app you're integrating with. It looks like this:
  ```
  https://subscribe-webhook.withampersand.com/v1/projects/PROJECT_ID/integrations/INTEGRATION_ID/installations/INSTALLATION_ID
  ```
2. Install the [HubSpot CLI](https://developers.hubspot.com/docs/developer-tooling/local-development/hubspot-cli/install-the-cli), then run `hs init` to connect it to your HubSpot account.
3. Create a private app with webhooks. When prompted, enter a name and location for the project:
  ```bash
  hs project create --project-base app --distribution private --auth static --features webhooks
  ```
4. In the new project, open `src/app/webhooks/webhooks-hsmeta.json`. Set `targetUrl` to the webhook URL from step 1, and add an `object.propertyChange` subscription for each custom field you want to track. See HubSpot's [webhooks guide](https://developers.hubspot.com/docs/apps/developer-platform/add-features/configure-webhooks) for the file format.
5. Run `hs project upload` to deploy the app to your HubSpot account.
6. In HubSpot, go to **Development** > **Projects**. If you don't see **Development** in the left sidebar, look under **More**.
7. Select your project, then click the app.
8. On the **Distribution** tab, click **Install now**.
9. Check the acknowledgment checkbox, then click **Connect App**.
