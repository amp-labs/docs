---
title: "Use with coding agent"
---

Ampersand offers two MCP servers that you can add to your favorite coding agent or IDE:

- The **builder MCP server** works with your Ampersand account. Your agent can use it to validate your `amp.yaml`, manage installations, connections and destinations, troubleshoot failed operations, and scaffold webhook handlers.
- The **docs MCP server** gives your agent the full Ampersand documentation, to help you build integrations quickly.

You can add either one, or both.

## Builder MCP server

Ampersand's builder MCP server is hosted at `https://builder-mcp.withampersand.com/v1/mcp`.

If you are using Claude Code, you can run this command:

```shell
claude mcp add ampersand --transport http "https://builder-mcp.withampersand.com/v1/mcp"
```

Then run `/mcp` in Claude Code, select `ampersand`, and choose **Authenticate**.

For other clients, add the server to the client's MCP configuration. Most clients accept a configuration like this one; see [Client specific configuration](#client-specific-configuration) for where it goes:

```json
{
  "mcpServers": {
    "ampersand": {
      "url": "https://builder-mcp.withampersand.com/v1/mcp"
    }
  }
}
```

### Signing in

The first time your agent connects, it opens your browser so you can sign in with your Ampersand account, the same way you sign in to the [Ampersand Dashboard](https://dashboard.withampersand.com). After you approve access, your agent connects automatically. You'll be asked to sign in again from time to time.

Your agent can work with the projects your Ampersand account has access to, with the same read or write permissions. If you're added to a project or removed from one, the change reaches your agent within a minute.

## Docs MCP server

Ampersand's docs MCP server is hosted at `https://docs.withampersand.com/mcp`.

If you are using Claude Code, you can run this command:

```shell
claude mcp add ampersand-docs --transport http "https://docs.withampersand.com/mcp"
```

## Client specific configuration

You can use Ampersand's MCP servers with any AI application that supports [MCP](https://modelcontextprotocol.io/clients). You need to add `https://builder-mcp.withampersand.com/v1/mcp`, `https://docs.withampersand.com/mcp`, or both to the appropriate configuration file or setting. Below are some of the most popular coding agents, and where to configure MCP servers for them:

| Client | Configuration File Location | Documentation |
|--------|------------------------------|---------------|
| Claude Code | `.mcp.json` (project scope) or `~/.claude.json` (user/local scope); or `claude mcp add` | [link](https://code.claude.com/docs/en/mcp) |
| Cursor | `~/.cursor/mcp.json` (global) or `.cursor/mcp.json` (project) | [link](https://cursor.com/docs/mcp) |
| JetBrains IDEs (Junie) | `~/.junie/mcp/mcp.json` (user) or `.junie/mcp/mcp.json` (project); or **Settings → Tools → Junie → MCP Settings** | [link](https://junie.jetbrains.com/docs/junie-plugin-mcp-settings.html) |
| Visual Studio Code | `.vscode/mcp.json` (workspace) or user `mcp.json` (**MCP: Open User Configuration**) | [link](https://code.visualstudio.com/docs/copilot/customization/mcp-servers) |
| Windsurf | `~/.codeium/windsurf/mcp_config.json` | [link](https://docs.windsurf.com/windsurf/cascade/mcp) |
| Zed | `context_servers` in `settings.json` (macOS/Linux: `~/.config/zed/settings.json`; Windows: `%AppData%\Zed\settings.json`) | [link](https://zed.dev/docs/ai/mcp) |

## Tips for better prompts

- Mention Ampersand in your prompt. For example, "How do I build X with Ampersand?"

- Name the project you want your agent to work in. For example, "In my Ampersand project Acme Sync, why did the last read of Salesforce contacts fail?"

- Ask your agent to verify field names against the provider's documentation. For example, "Verify that the field names are real field names for the Account object, according to Salesforce documentation."

- Ask your agent to refer to Ampersand's OpenAPI spec at https://github.com/amp-labs/openapi.
